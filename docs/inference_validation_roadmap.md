# Inference Validation Roadmap

This roadmap has been split into two purpose-built documents.

- [Inference Guide For Physicists](inference_validation_for_physicists.md)
  - Narrative explanation for physicists, especially readers who are new to Bayesian inference.
  - Explains prior predictive checks, posterior predictive checks, input recovery, identifiability, and why deeper cloud-wind parameters should be added cautiously.

- [Inference Validation Agent Workplan](inference_validation_agent_workplan.md)
  - Execution plan for future coding agents.
  - Defines task order, dependencies, parallelizable work streams, deliverables, acceptance criteria, and test commands.

Use the physicist guide to decide what the inference program is scientifically trying to learn. Use the agent workplan to implement the scripts, tests, and reports in a safe order.
